## `whoami`

I'm a curious builder exploring the intersection of **defensive cybersecurity, practical developer tools, and interactive web experiences**.

I like projects that are useful, understandable, and a little bit over-engineered in the fun way.

- 🔍 Building local-first security tools that keep experiments safe and transparent
- 🏎️ Turning browser APIs into playable worlds with engines, tracks, boosts, and rivals
- 🧪 Learning by shipping prototypes, breaking them, and making them better
